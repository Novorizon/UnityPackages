# RTree

Unity 2022.3 空间索引包，程序集/命名空间为 RTree，不依赖其他自有包。

包含 RTree、DynamicAabbTree、StaticBvh、TriangleBvh、LooseOctree、KdTree，分别位于 Runtime 的独立目录，共用一个包。
