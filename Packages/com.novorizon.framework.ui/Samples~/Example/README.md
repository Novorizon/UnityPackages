# UI Categories：业务脚本片段

这些脚本用于学习如何继承 UIPage/UIPopup/UIPanel/UIToast、使用作用域与结果，不附带手工制作好的 Prefab 或场景。

直接运行完整演示时，在 Package Manager Import **UI Demo**，点击 Tools / Novorizon / Demos / Create UI Demo Scene；该演示会自己创建模板、按钮与列表。

若使用本组片段，请创建对应 UIView Prefab，绑定序列化的按钮/Text/ScrollRect 字段，并按脚本与项目资源接口约定注册位置。默认 Resources 路径例如 UI/Pages/MainMenuPage；游戏也可用 IUIAssetLoader 解释自己的地址。
